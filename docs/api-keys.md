# Ключи API и доступы: что и куда добавлять

Секреты делятся на два вида и хранятся в разных местах. **Ни один из них
не нужно отправлять в чат, в репозиторий или в мессенджеры.**

| Вид секрета | Где хранится | Кто вводит |
|---|---|---|
| Ключи приложения и OAuth-приложения Google/Яндекс | файл `.env` в корне проекта | администратор, один раз |
| Доступы к аккаунтам систем (API-ключи, OAuth-токены) | база данных, **в зашифрованном виде** | администратор, в интерфейсе: «Подключения → Подключить аккаунт» |

**Готовность коннекторов:** все 9 систем работают с реальным API — Search Console, GA4,
Яндекс.Метрика, Яндекс.Вебмастер, Bing, Topvisor, SE Ranking, PageSpeed Insights и CrUX.

## Быстрый старт: PageSpeed Insights и CrUX

Обеим системам нужен один API-ключ Google Cloud, без OAuth и экрана согласия.

### Шаг 1. Получить ключ в Google Cloud (5 минут)

1. Откройте <https://console.cloud.google.com/> под рабочим Google-аккаунтом компании
   (не личным: ключ должен пережить уход сотрудника).
2. Вверху — выбор проекта → **New project** → название, например `seo-dashboard` → **Create**.
   Если проект для дашборда уже есть, выберите его.
3. **APIs & Services → Library** → найдите и нажмите **Enable** для двух API:
   - **PageSpeed Insights API**;
   - **Chrome UX Report API**.
4. **APIs & Services → Credentials → Create credentials → API key**. Скопируйте ключ.
5. Ограничьте ключ (рекомендуется): в списке ключей нажмите на него →
   **API restrictions → Restrict key** → отметьте *PageSpeed Insights API* и
   *Chrome UX Report API* → **Save**. Тогда утёкший ключ нельзя использовать для других API.

Оба API бесплатны. Квоты: PSI — 25 000 запросов в сутки, CrUX — 150 запросов в минуту.
Проект на 30 сайтов с 3 URL расходует около 540 запросов PSI в сутки.

### Шаг 2. Добавить ключ в дашборд (администратор)

1. **Подключения → + Подключить аккаунт**.
2. Система — **PageSpeed Insights**, способ — **API-ключ**, название — например
   «Google Cloud, seo-dashboard». Вставьте ключ → **Сохранить**.
3. Повторите для системы **Core Web Vitals (CrUX)** с тем же ключом.
4. В списке нажмите **Проверить** у каждой записи. Статус «Работает» — ключ принят.
   Проверка PSI делает настоящий замер и занимает до 30 секунд.

Если проверка не прошла — текст ошибки подскажет причину:

| Сообщение | Что сделать |
|---|---|
| «API-ключ недействителен» | ключ скопирован не полностью или удалён — скопируйте заново |
| «API не включён в проекте Google Cloud» | шаг 1.3: включите API именно в том проекте, где создан ключ |
| «превышена квота» | подождите минуту (CrUX) или до следующих суток (PSI) |

### Шаг 3. Подключить к проекту

1. **Проекты → + Новый проект** (администратор): название и домен, например `site.by`.
2. В настройках проекта → **+ Подключить система** → **PageSpeed Insights** → аккаунт →
   ресурс (главная страница сайта подставляется из домена) → **Пробный запрос** → **Сохранить**.
   Главная страница автоматически добавится в «URL для PageSpeed Insights»; добавьте туда
   по одному URL на каждый важный шаблон (каталог, карточка товара, статья).
3. Так же подключите **Core Web Vitals (CrUX)**: ресурс — адрес сайта с `www` или без,
   как сайт реально открывается. Если пробный запрос сообщает «нет данных» — у сайта
   недостаточно посещений из Chrome для отчёта Google; попробуйте второй вариант адреса.

### Что появится на дашборде

- **CrUX** — сразу после подключения: недельная динамика LCP, INP, CLS, FCP, TTFB
  примерно за 40 недель (это вся история, которую хранит Google).
- **PSI** — первый замер выполняется сразу после подключения (1–2 минуты на проект),
  дальше — каждую ночь. Каждый URL проверяется 3 раза на мобильных и ПК, сохраняется
  медиана. Историю PSI задним числом получить нельзя: график наполняется день за днём.

## Topvisor и SE Ranking

Коннекторы **не запускают проверки позиций** (это платно), а забирают результаты съёмов,
которые сервис делает по своему расписанию. Поисковики и регионы берутся из настроек
проекта в самом сервисе. При подключении загружается только последний съём; дальше
история копится в дашборде каждую ночь.

Средняя позиция, видимость и распределение по топам считаются дашбордом по единой
формуле для обоих сервисов, поэтому видимость может немного отличаться от значения
в интерфейсе Топвизора или SE Ranking.

### Topvisor

1. В Топвизоре: **Профиль → Настройки → API** (раздел «Доступ к API»). Скопируйте
   **User ID** и **API-ключ**. Ключ показывается один раз — сохраните его в менеджере паролей.
2. В дашборде (администратор): **Подключения → + Подключить аккаунт** → система **Topvisor** →
   **API-ключ** → заполните **User ID Топвизора** и **API-ключ** → **Сохранить** → **Проверить**.
   При успехе в статусе будет число проектов в аккаунте.
3. В настройках проекта дашборда: **+ Подключить систему → Topvisor** → аккаунт → проект
   Топвизора из списка (видны его поисковики и регионы) → **Пробный запрос** → **Сохранить**.

> Если отслеживается один регион и на ПК, и на телефоне, это два отдельных среза:
> «Минск» и «Минск · моб.».

### SE Ranking

1. Проверьте тариф: Project API входит во все текущие тарифы, а на старых Essential и Pro
   (v1–v6) покупается аддоном. Без него проверка вернёт «нет доступа … тариф».
2. В SE Ranking: **API → Dashboard** → таблица **API Keys** → скопируйте ключ.
3. В дашборде: **Подключения → + Подключить аккаунт** → система **SE Ranking** → **API-ключ**
   → поле **API-токен** → **Сохранить** → **Проверить**.
4. В настройках проекта: **+ Подключить систему → SE Ranking** → аккаунт → проект →
   **Пробный запрос** → **Сохранить**.

Ограничение API SE Ranking — 5 запросов в секунду; дашборд делает 5–6 запросов на проект.

## 1. Файл `.env`

Создаётся скриптом `scripts\setup.ps1` (или командой `python -m app.cli init-env`)
из шаблона [.env.example](../.env.example). Откройте его в редакторе и заполните
нужные строки; после изменения перезапустите приложение.

```dotenv
# Создаются автоматически — не меняйте после начала работы
SECRET_KEY=...
ENCRYPTION_KEY=...

# OAuth-приложение Google (GSC, GA4)
GOOGLE_CLIENT_ID_1=
GOOGLE_CLIENT_SECRET_1=

# OAuth-приложение Яндекса (Метрика, Вебмастер)
YANDEX_CLIENT_ID_1=
YANDEX_CLIENT_SECRET_1=
```

### Одно приложение на все аккаунты

Одного OAuth-приложения достаточно для любого числа аккаунтов: кнопка
«Войти через Google/Яндекс» открывает страницу провайдера, где выбирается аккаунт.
Новые входы всегда идут через приложение `_1`.

Если раньше аккаунты подключались через другие приложения, их ключи оставьте
в `.env` под следующими номерами (`_2`, `_3`…): токен доступа обновляется только
тем приложением, которое его выдало. Одно и то же имя ключа дважды писать нельзя —
из повторов читается только последнее. Ключи без номера (`GOOGLE_CLIENT_ID=`)
тоже работают и считаются первым приложением.

### Google: OAuth-приложение для Search Console и GA4

Делается один раз в том же проекте Google Cloud, где создан ключ PSI/CrUX.

1. <https://console.cloud.google.com/> → выберите проект дашборда.
2. **APIs & Services → Library** — включите ещё три API:
   *Google Search Console API*, *Google Analytics Data API*, *Google Analytics Admin API*.
3. **APIs & Services → OAuth consent screen** (в новом интерфейсе — **Google Auth Platform**):
   - тип пользователей — **External**; название приложения, например «SEO-дашборд»,
     e-mail поддержки и разработчика;
   - **Scopes** можно не заполнять — приложение само запросит права при входе;
   - **Publish app** — перевести в статус **In production**.
   > В статусе «Testing» refresh-токены истекают через 7 дней, и сбор по всем
   > аккаунтам будет падать каждую неделю. Для внутренних read-only прав проверка
   > Google обычно не нужна: при входе появится предупреждение «Google не проверил
   > это приложение» → **Дополнительные настройки → Перейти на страницу…**.
4. **APIs & Services → Credentials → Create credentials → OAuth client ID**:
   - Application type — **Web application**;
   - **Authorized redirect URIs** → `http://localhost:8000/api/oauth/google/callback`
     (на сервере — `https://<ваш-домен>/api/oauth/google/callback`; адрес можно
     скопировать на странице «Подключения» дашборда).
5. Скопируйте **Client ID** и **Client secret** в `.env`:
   `GOOGLE_CLIENT_ID_1=…`, `GOOGLE_CLIENT_SECRET_1=…` → перезапустите приложение.
6. В дашборде: **Подключения → Войти через Google** → выберите аккаунт на странице
   Google → разрешите доступ. Появятся два доступа — «Google Search Console» и
   «Google Analytics 4» с e-mail аккаунта. Повторите для каждого Google-аккаунта.

### Яндекс: OAuth-приложение для Метрики и Вебмастера

Яндекс выдаёт код подтверждения на своей странице `https://oauth.yandex.ru/verification_code`,
а код вставляется в дашборд. Адрес дашборда регистрировать в приложении не нужно —
способ одинаково работает на localhost и на сервере.

1. <https://oauth.yandex.ru/client/new> под рабочим Яндекс ID.
2. Название, например «SEO-дашборд». **Redirect URI** оставьте предложенный Яндексом:
   `https://oauth.yandex.ru/verification_code`.
3. **Доступ к данным** — отметьте:
   - Яндекс.Метрика: *Получение статистики, чтение параметров своих и доверенных счётчиков*
     (`metrika:read`);
   - Яндекс.Вебмастер: *Получение информации о сайтах* (`webmaster:hostinfo`).
4. Скопируйте **ClientID** и **Client secret** в `.env`:
   `YANDEX_CLIENT_ID_1=…`, `YANDEX_CLIENT_SECRET_1=…` → перезапустите приложение.
5. В дашборде: **Подключения → Войти через Яндекс**:
   1. **Открыть страницу входа Яндекс** — откроется новая вкладка; войдите в нужный
      аккаунт и нажмите **Разрешить**;
   2. Яндекс покажет код подтверждения — скопируйте его, вставьте в окно дашборда
      и нажмите **Подключить**.

   Появятся доступы «Яндекс.Метрика» и «Яндекс.Вебмастер» с логином аккаунта.
   Код действует 10 минут и срабатывает один раз. Для следующего аккаунта Яндекса
   выйдите из текущего в браузере (или откройте ссылку в окне инкогнито) и повторите.

### Bing Webmaster

1. <https://www.bing.com/webmasters> → значок шестерёнки **Settings → API access** →
   **API Key** → **Generate** → скопируйте ключ.
2. В дашборде: **Подключения → + Подключить по API-ключу** → **Bing Webmaster** →
   вставьте ключ → **Сохранить** → **Проверить**.

Bing не отдаёт среднюю позицию по сайту и список URL с ошибками — в блоке Bing
только клики, показы, CTR, карты сайта и счётчики ошибок обхода.

### Если вход не работает

| Сообщение | Причина |
|---|---|
| «Не настроено OAuth-приложение …» / «нужно OAuth-приложение» | не заполнен `*_CLIENT_ID_N`/`*_CLIENT_SECRET_N` в `.env`, одно имя ключа повторяется несколько раз (нужны номера) или приложение не перезапущено |
| «OAuth-приложение, через которое подключён аккаунт, больше не указано в .env» | ключи приложения удалили или изменили — верните их или нажмите «Войти заново» |
| Google: «redirect_uri_mismatch» | адрес возврата в OAuth client не совпадает с адресом на странице «Подключения» |
| Яндекс: «redirect_uri не совпадает с Callback URL» | в приложении Яндекса должен стоять Redirect URI `https://oauth.yandex.ru/verification_code` |
| Яндекс: «Код не подошёл» | код уже использован или прошло больше 10 минут — откройте страницу входа заново |
| «не выдал refresh-токен» | Google-аккаунт уже давал доступ раньше: удалите доступ «SEO-дашборд» на myaccount.google.com → Безопасность → Сторонние приложения и войдите снова |
| «доступ отозван или истёк … Переподключите» | токен отозван или OAuth-экран в статусе Testing — нажмите «Войти заново» у доступа |
| «API не включён в проекте Google Cloud» | шаг 2 раздела Google |

## 2. Доступы к аккаунтам — в интерфейсе

Меню **Подключения → Подключить аккаунт** (только администратор). Ключ вводится в поле типа «пароль»,
на сервере шифруется ключом `ENCRYPTION_KEY` и обратно не отображается.

| Система | Способ | Где взять |
|---|---|---|
| Google Search Console, GA4 | вход через Google (OAuth) — по доступу на каждый из 8 аккаунтов | кнопка «Войти через Google» |
| Яндекс.Метрика, Вебмастер | вход через Яндекс (OAuth) | кнопка «Войти через Яндекс» |
| PageSpeed Insights, CrUX | API-ключ | Google Cloud Console → Credentials → API key |
| Bing Webmaster | API-ключ | Bing Webmaster Tools → Settings → API access |
| Topvisor | User ID + API-ключ | Топвизор → Настройки аккаунта → API |
| SE Ranking | API-токен (Project API) | SE Ranking → Настройки → API |

> **SE Ranking:** Project API входит во все текущие тарифы; на старых Essential
> и Pro (v1–v6) покупается аддоном. Проверьте тариф до подключения.

## 3. Полная очистка данных

Удалить все проекты, доступы и собранные данные (учётные записи, команда и справочники
сохраняются):

```powershell
cd backend
.\.venv\Scripts\python -m app.cli purge-data --with-logs
```

## 4. Что делать при утечке или уходе сотрудника

- Сменить пароль общей учётной записи: «Учётные записи → Сменить пароль»
  (администратор) — активные сессии завершатся.
- Отозвать доступ в самой системе (Google Account → Security → Third-party access;
  Яндекс ID → Доступы) и переподключить аккаунт в приложении: «Подключения → Переподключить».
- API-ключи перевыпустить в кабинете сервиса и заменить через «Переподключить».
